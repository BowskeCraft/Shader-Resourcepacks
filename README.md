# Bowske's Shader Resourcepacks

This is a resource pack that cheanges minecraft's visual through shaders.

> [!CAUTION]
> For technical reasons, you may not get the correct output on specific environmens. In the worse case, Even if you report some bugs I may not be able to reproduce itself in my setup. Please understand that I cannot guarantee that I can fix this.

## Features

- Thickness-dependent alpha correction
- Chromatic abberation
- Depth of field

## Required Versions / Settings

- Minecraft:Java Edition 26.1
- No Shader Mods compatible
